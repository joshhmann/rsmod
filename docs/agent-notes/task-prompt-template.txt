  ## Top mistakes that break the build/server (Do NOT do these):
  - `bindScript<T>()` in PluginModule — does NOT exist, delete it. Scripts are auto-discovered.
  - `private object X : NpcReferences()` — must be `internal` or `public`, NEVER `private`.
  - Using `String` as a placeholder for `ObjType` or `StatType`. Use real refs (`objs.x`, `stats.y`).
  - `find("name", fallbackId)` — if the sym entry exists, use `find("name")` only to avoid hash mismatch crashes.
  - Duplicate `edit(npc)` entries in NpcEditor for the same NPC across different modules (causes infinite startup loop).
  - `mes(player, "text")` — use `mes("text")` inside ProtectedAccess.
  - `Thread.sleep()` — BANNED. Freezes the server. Use `delay(ticks)`.
  - `var` inside a singleton `object` — BANNED. Global mutable state breaks multiplayer. Store state on `Player`.
  - `println()` — BANNED in content/api. Use RSMod's SLF4J `InlineLogger()`.
  - `invAdd()` without checking `.success` — BANNED. Fails silently if full. Check `.success` or use `invAddOrDrop()`.
  - Interface IDs > 924 in `.local/interface.sym` (rev233 max = 924).
